# SmartMart Motors – Changelog

## 1.0.0 – 2026-08-04

### Added

- Production Next.js 15 App Router storefront with dark glassmorphism design system
- Public pages: Home, About, Products, Product detail, Categories, Contact, FAQ, Privacy, Terms
- Admin dashboard with products, categories, brands, messages, media, content, FAQs, users, analytics, SEO, settings, audit logs
- Prisma schema + seed data and Supabase SQL/RLS migration
- NextAuth credentials authentication and role-based access
- Cloudinary upload API, contact form API, analytics event API
- SEO: sitemap, robots, manifest, metadata helpers, JSON-LD builders
- Analytics hooks for GA4, GTM, Microsoft Clarity, Meta Pixel
- Security middleware headers, rate limiting, Zod validation
- GitHub Actions CI, Docker Compose, deployment documentation
